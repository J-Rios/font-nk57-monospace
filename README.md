
# NK57 Monospace

The public-domain NK57 typeface was designed by Ray Larabie. His goal was to make a programmer-friendly typeface with multiple widths, something that would let coders fit a precise number of characters on different display panels. The family launched with sixty styles in total: six weights, five widths, and italics.
